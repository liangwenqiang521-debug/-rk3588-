# 漏标候选人工复核指南

生成时间：2026-10-14。数据来源：`模型训练/_miss_candidates_{train,val}.csv`（判据：conf≥0.45 + 与最近 GT IoU<0.20 + 预测类∈图内已有 GT 类）。

## 怎么看图

每页 20 个 cell，每格一张裁剪图：

- **红粗框** = 模型预测（候选漏标框），标注了类别和置信度
- **绿细框** = 数据集里已有的 GT 标注

**判读标准**：红框内是明确的缺陷纹理、且红框不与任何绿框重叠 → 记 **漏标（应补框）**；
红框内是背景/伪缺陷（水渍、光照、轧纹）→ 记 **误报（不补）**；拿不准 → 记 **存疑**。

## 分级与页数

| 档位 | val 页数 | train 页数 | 说明 |
|---|---|---|---|
| conf≥0.60 | p01–03 | p01–05 | **优先看**，143 个，漏标概率最高 |
| 0.50≤conf<0.60（含高段） | p01–07 | p01–16 | 次优先 |
| 0.45≤conf<0.50 | p01–03 | p01–09 | 低优先，可抽查 |

文件名：`review_{split}_conf{lo}-{hi}_p{页码}.png`。

## 复核后的动作

1. 把确认漏标的图名/框记录下来（或直接在 CSV 里加一列 `verdict`）。
2. val 的漏标 → 影响**评估可信度**（mAP/F1 被低估）；train 的漏标 → 影响**训练**。
3. 确认比例明确后：修标注（需要你确认才动）→ `_make_split.py --mode stratified --write` → 重训 100 轮。

预期收益参考（oracle 上界）：F1 0.711 → 0.751（+4.0pp）。
