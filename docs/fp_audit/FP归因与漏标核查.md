# 39 类模型 FP 归因报告：瓶颈不是背景误报，是标注缺失

- 日期：2026-10-14
- 模型：50 轮基线 `runs/steel39_yolo11n_640/weights/best.pt`（当前板端在役）
- 数据：`缺陷检测扩展` val 5296 张（负样本 200 / 有缺陷 5096，GT 10226 框）
- 推理：conf≥0.01 一次缓存（`模型训练/_val_preds_conf001.pkl`），以下统计在 th=0.20 上复算
- 口径：NMS IoU 0.45 / 匹配 IoU 0.50 / 一对一贪心，与 `_calib_thres39.py` 一致
- 配套脚本：`fp_attrib.py`（归因）、`fp_deep.py`（下钻）、`fp_crops.py`（拼图），临时目录，如需复用再入库

## 1. 结论一句话

**2647 个 FP 全部出自有缺陷的图**；模型对 200 张纯背景图零误报（只有 1 张产出 1 个
conf=0.011 的框）。FP 的大头是**数据集漏标 / 标注不完整**，不是模型臆造，更不是背景混淆。

### 2.3 排除掉的两个假说

- **背景误报**：零。负样本治理无收益空间（此前 10-12 的"瓶颈是背景误报"判断有误，撤回）。
- **NMS 太松**：与其它预测框 IoU≥0.30 的 FP 只占 20.1%；模拟类无关 NMS 0.45→0.25，
  FP −302 但 FN +109，**F1 仅 +0.0039**。不是解药。

### 2.4 无解释检测的判定：漏标而非臆造

取高置信（conf≥0.45）且 IoU<0.20 的 240 个框（A 组），裁图人工判读
（`fp_sheet_A_无解释高置信.png`，红框=FP，绿框=GT）：

| 证据 | 数值 | 随机基线 |
|---|---:|---:|
| 预测类别 == 图内已有 GT 类别 | **81.7%** (196/240) | ~7.2% |
| 预测类别 == 最近 GT 类别 | 81.2% (195/240) | — |
| 数据源分布 | um_* 221 / gc_* 19 | — |

B 组（IoU 0.25~0.50 的框偏移，428 个）同类率 **97.4%**。臆造不可能达到这种同类率——
模型是在图内**找到了同类缺陷的其它实例**，只是没人标；拼图上也能看到红框覆盖明显
的缺陷纹理而附近没有绿框（如 #3 圆形夹杂、#12/#24/#35 patches 深色斑块）。

唯一的系统性跨类混淆：`welding_line↔crescent_gap`（gc_* 源，14 例），疑似该源
标注约定与其它源不一致。

## 3. 漏标回收的指标上界（oracle）

假设"同类 + 高置信"的未匹配检测都是漏标（自证偏置，只当上界看）：

| 口径 | TP | FP | P | R | F1 |
|---|---:|---:|---:|---:|---:|
| 基线（现状） | 7097 | 2647 | 0.7283 | 0.6940 | 0.7108 |
| 回收 conf≥0.75 全部 | 7151 | 2593 | 0.7339 | 0.6956 | 0.7142 |
| 回收 conf≥0.60 同类 | 7361 | 2383 | 0.7554 | 0.7017 | 0.7276 |
| 回收 conf≥0.45 同类 | 7736 | 2008 | 0.7939 | 0.7120 | **0.7507** |

→ 标注修复的理论天花板 **F1 +4.0pp**；按人工复核确认率 60~80% 折算，实际预期
**+2.5~3.5pp**。FN 3129 不受此影响（那是"GT 有而模型没有"），且其中还会有一部分
是"误标"造成的假 FN，真实天花板更高。

## 4. 对后续计划的影响

| 原计划项 | 判定 |
|---|---|
| ① 负样本过采样 + 重训 | **作废**。背景零误报，无头寸。 |
| per-class 阈值 | 只能压 conf<0.33 的那半 FP，代价召回（已有实测 −0.008 F1），不建议默认部署。 |
| NMS 调紧 | 收益 +0.004 F1，可顺手做但不值得单独做。 |
| ② 全池分层重划分 + 重训 | 仍值得（可信度 + 小类统计），但**应排在标注修复之后**，否则 8h 重训建立在脏标注上。 |
| **新增：标注修复** | 唯一能同时压 FP 的动作。候选框可半自动生成（同类+高置信+低 IoU），人工只做确认。 |

## 5. 论文可写点

1. FP 系统性归因方法（按图归属 + IoU 分层 + 类别同现率检验）——比单看 mAP 更有诊断价值。
2. "评估集漏标导致模型精度被系统性低估"的实证：同类率 81.7% vs 随机 7.2%。
3. 修正口径后的指标区间（0.711 ~ 0.754）及其自证偏置的诚实说明。
4. 数据源级标注约定差异（gc_* 源 welding_line/crescent_gap）。
