# DESIGN：工业缺陷检测系统 · 应用场景与落地地图

> 设计依据：`design-principle.md`（通用法则） + `STORY.md`（项目叙事） + 用户选定风格 **A · 工业科技蓝**。
> 场景路由：项目汇报 / 答辩 —— 属职场通用技术汇报，**不命中**学术/咨询/红金三个预设分支 → 走通用设计原则。

## 1. 画布与全局母版

- **画布**：1280 × 720 px（16:9）。
- **母版三区**（内容页严格复用）：

| 母版区 | 垂直位置 | 高度 | 规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 0–120px | 120px（含上 padding 20） | 主标题 36px bold，色 `#0B1C33`；左侧 4px × 36px 主色竖条 |

| **C · 页脚条** | 660–720px | 60px（含下 padding 20） | 左：项目名「工业表面缺陷检测系统」14px `#7A8899`；右：页码 `NN / 12` 14px `#7A8899` |

- 封面 / 章节扉页 / 结束页可省略 C 区或采用自定义版式。

## 2. 颜色系统（≤ 4 hex）

| 角色 | HEX | 用途 | 面积占比 |
| :--- | :--- | :--- | :--- |
| **主色 深空蓝** | `#0B3D91` | 标题栏竖条、章节扉页底、大色块、主数据 | ≤ 60% |
| **辅色 科技青** | `#00B4D8` | 卡片头部渐变终点、图表第二系列、次级色块 | ≤ 30% |
| **强调色 信号橙** | `#FF7A18` | 巨型数字、核心 KPI、CTA、警报点 —— 只出现在焦点元素 | ≤ 10% |
| **中性色** | `#0B1C33`（文本主色）/ `#F4F7FB`（浅底）/ `#7A8899`（辅助文本） | 文本、页脚、边框、浅底 | 剩余 |
| 背景 | `#FFFFFF` / `#F4F7FB` | 内容页浅底；封面与扉页用深底 | — |

> ⚠️ 注意：强调色为**信号橙**，不是红色。这样 NG 语义（在检测界面上是红色）与 PPT 的强调色不冲突；
> 若某页需表达"缺陷/报警"，用橙色作为该页唯一强调即可。

### 2.1 色彩节奏规则

- **Hero 页（P1 / P5 / P12）**：强调色占比可到 15–18%；P1、P12 用深底 + 光带。
- **Supporting 页**：强调色 ≤ 5%，辅色 ≤ 20%，主色走浅底 + 少量深色块。
- 至少 2 页色彩比例与其他页显著不同：**P1 / P12 深底** vs 其余浅底；**P5** 强调色爆发 ➜ 满足。

### 2.2 渐变与半透明策略（本项目声明）

- 主渐变：`linear-gradient(135deg, #0B3D91 0%, #00B4D8 100%)` —— 用于卡片头部条、章节扉页底。
- 浅色半透明覆盖：`rgba(11,61,145,0.06)` —— 用于大面积极浅底块（如场景卡底）。
- 深底图蒙版：`rgba(6,20,40,0.62)` —— 封面 / 扉页 / 结束页压在底图上，保证白字可读。
- 卡片浮起：`boxShadow: '0 6px 22px rgba(11,61,145,0.10)'`。
- 元素重叠：底层 `opacity: 0.15~0.25`。

## 3. 字体系统

- **中文字体**：标题 = 思源黑体 Bold；正文 = 思源黑体 Regular。**西文/数字** = Inter。
- **巨型数字/锚点**：Inter Bold，与正文字重明显拉开。

| 层级 | 字号(px) | 字重 | 行高 | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 76 | bold | 1.2 | 仅封面 |
| 章节大字 | 64 | bold | 1.1 | 章节扉页、结束页 |
| **巨型数据/锚点** | **72–110** | **bold** | **1.0** | 核心数据、锚点数字，每页 ≥ 1 个 |
| 页面主标题（A 区） | 36 | bold | 1.3 | 每页固定 |
| 副标题 / 卡片小标题 | 26 | bold/600 | 1.4 | 卡片头 |
| 正文 | 23 | regular | 1.55 | 段落 |
| 引文 | 21 | italic | 1.5 | 「」 |
| 脚注 / 页码 | 14 | regular | 1.4 | 页脚 C 区 |

## 4. 信息密度门禁（本项目取值）

| 页面类型 | 最少元素 | 正文字数下限 | 图/表下限 | 主视觉占 B 区 |
| :--- | :--- | :--- | :--- | :--- |
| 封面 | 主标题+副标+主视觉 | 20 | 1 | ≥ 35% |
| 目录 | 4 条 + 引导句 | 120 合计 | 0–1 | — |
| 内容页 · 单主题 | 标题+正文+主视觉 | 180 | 1 | ≥ 30% |
| 内容页 · 卡片组 | 标题+引导+N 卡 | 每卡 ≥ 100 | 0–N | — |
| 数据/图表页 | 标题+主图+洞察 | 80 | 1 主图 | ≥ 50% |
| 章节过渡 | 大字 + 一句小标 | 30 | 1 | ≥ 40% |
| 结束页 | 金句 + 落款 | 20 | 0–1 | — |

- **默认留白上限**：常规内容页 ≤ 35%；封面 / 扉页 / 结束页不受限。
- **容器填充率 ≥ 85%**；卡片尾部元素用 `marginTop:'auto'` 钉底；同行兄弟卡三段等高对齐。

**生图风格统一声明**：全篇 L1/L2 一律为**工业摄影写实风**（工业场景、金属质感、冷蓝调），

**允许 SVG**：流程图、时间轴、三步路径箭头、迁移矩阵框、巨型数字、L3 徽标、底图网格。

**生图策略（2026-10-09 调整）**：仅封面 P1 使用 `ImageGen` 写实底图；

零额外生图消耗。SVG 承担"氛围 + 结构"双重职责，用大面积渐变块、光带、网格、节点连线保证视觉重量。

## 7. 动笔自检清单（每页提交前）

1. A/B/C 三区齐全，标题块位置全篇一致，C 区右下页码 `NN / 12`；
2. 标题块右侧无装饰小图；
3. 本页 L1 占 B 区 ≥ 30%（Hero ≥ 40%，数据页 ≥ 50%）；
4. 仅用本文件列出的 4 种 hex 与 2 套字体；
5. 与上一页版式不同；常规页留白 ≤ 35%；
6. 本页 ≥ 1 视觉锚点（≥44px 元素 或 ≥40% B 区图）；
7. 与上一页视觉重量差异（>1.5:1 或结构不同）；
8. 强调色只出现在焦点元素；
9. role 与 STORY 一致（hero 有 ≥40% 主视觉或 ≥48px 锚点）；
10. 章节扉页编号 01–04 连续，标题与目录逐字一致。
