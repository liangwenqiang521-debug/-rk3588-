## 2. 颜色系统（≤ 4 hex）

| 角色 | HEX | 用途 | 面积 |
| :--- | :--- | :--- | :--- |
| **主色 深空蓝** | `#0B3D91` | 竖条、扉页底、大色块、主数据 | ≤ 60% |
| **辅色 科技青** | `#00B4D8` | 渐变终点、图表第二系列、状态点 | ≤ 30% |
| **强调色 信号橙** | `#FF7A18` | 巨型数字、核心 KPI、重点标记 | ≤ 10% |
| **中性色** | `#0B1C33` 文本 / `#F4F7FB` 浅底 / `#E1E9F2` 描边 / `#5C6E82` 辅助文本 / `#9AA9B8` 页脚 | 文本、卡片、边框 | 剩余 |
| 背景 | `#FFFFFF` / `#F4F7FB`；封面与扉页深底 `#061428` | — | — |

### 2.1 色彩节奏
- Hero 页（P1/P7/P10/P14）：强调色 15–18%；P1/P7/P14 深底或大数字爆发。
- Supporting 页：强调 ≤ 5%，辅 ≤ 20%。
- 显著不同的页：P1/P3/P7/P9/P14（深底或大数字） vs 其余浅底 ✅

### 2.2 渐变/半透明
- 主渐变 `linear-gradient(135deg, #0B3D91 0%, #00B4D8 100%)`：卡片头、扉页底。
- 卡片头细条 `linear-gradient(90deg,#0B3D91,#00B4D8)`。
- 深底蒙版 `rgba(6,20,40,0.62)`；浅底块 `#F4F7FB`。
- 卡片浮起 `boxShadow: 0 6px 22px rgba(11,61,145,0.10)`。

## 7. 动笔自检（每页提交前）

1. A/B/C 三区齐全，标题位置全篇一致，C 区右下 `NN / 14`；
2. 标题块右侧无装饰小图；
3. L1 占 B 区 ≥ 30%（hero ≥ 40%，数据页 ≥ 50%）；
4. 仅用 4 hex + 2 字体家族；
5. 与上一页版式不同；常规页留白 ≤ 35%；
6. ≥ 1 视觉锚点（≥44px 元素或 ≥40% B 区图）；
7. 与上一页视觉重量差异显著；
8. 强调色只在焦点元素；
9. role 与 STORY 一致；
10. 扉页编号 01–03 连续、标题与目录逐字一致。
