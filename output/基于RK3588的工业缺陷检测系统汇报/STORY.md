# STORY：基于 RK3588 的轻量化工业缺陷检测系统 —— 模型训练与边缘部署分析

## 1. 这份 PPT 要解决的问题

对标《模型训练分析报告》（Orin Nano 39 类项目），用同一套叙事骨架讲清 rk3588 6 类项目的完整闭环：
**数据从哪来 → 模型怎么训 → 为什么必须做级联 → 上板后跑得怎么样 → 还差什么。**

受众：答辩 / 项目汇报场景的技术听众。调性：证据驱动、有数字、敢写失败结论。

---

## 2. 核心叙事主线（一句话）

> 6 类 NEU 热轧带钢缺陷，在 RK3588 上做到 **holdout mAP50 0.7393 + 域外误检 0% + 板端 p50 196ms**；
> 关键不是把模型训得更大，而是用**负样本闭环发现 tradeoff、用双模型级联绕开 tradeoff**。

---

## 3. 三个必须讲透的"判断"

1. **负样本闭环是不可跳过的一步**。纯缺陷集训的模型对"正常纹理"完全无约束：
   DAGM 无缺陷图误检 64.4%，换成 NEU 干净裁块也有 35.5%。这不是精度问题，是**域外泛化**问题。
2. **但这个 tradeoff 调不出来，只能绕开**。加负样本重训后误检归零，可 180 真实图 top1 从
   97.8% 掉到 95.6%；1:1 和 1:2 两档比例都试过，都是 95.6% —— **比例解不开**。
3. **所以上双模型级联**：一级 filter 判"有没有缺陷"（0 框直接放行），二级 _640 精判类别。
   等价于"用结构换指标"，**同时拿到误检 0% 和 top1 97.8%**，且上位机协议零改动。

### P4 缺陷类型与强弱
- 数据：6 类均匀分布，每类 300 张（train 240 / val 60）
- 三档（按 holdout Recall）：
  - 强 patches 0.922 / pitted_surface 0.822 / scratches 0.810
  - 中 inclusion 0.776 / rolled-in_scale 0.734
  - 弱 crazing 0.597（Precision 仅 0.483）
- 结论：crazing 是最弱类；已验证阈值扫描与专项微调均无效（见 P5/P6）

### P6 各类准确度
- 双序列柱状图：6 类 Recall / Precision（holdout）

  - patches 0.922 / 0.866

### P7 负样本闭环与双模型级联（全篇重点）
- 左：问题 —— 纯缺陷集训模型对正常纹理无约束，DAGM val 误检 64.4%（NEU 干净裁块 35.5%）
- 中：失败尝试 —— 加负样本重训（1:1 / 1:2）→ 误检 0%，但 180 图 top1 97.8% → 95.6%，比例解不开
- 右：方案 —— 双模型级联
  - 一级 `negdagm_filter.rknn` 判"有无缺陷"，0 框直接 OK（~70ms）
  - 二级 `best_neu6_640.rknn` 精判类别（~140–215ms）
  - FP16 各 7.5MB；协议与单模型完全兼容，上位机零改动
- 效果条：误检 0% + top1 97.8% + mAP50 0.7393 不掉 + p50 196ms

### P8 板端部署与工程
- 指标卡 ×4：196ms（p50）／ 216ms（p95）／ 1445 帧（压测零异常）／ 0（误检）
- 表格：维度 / 实测 / 说明
  - 延迟 p50/p95/p99：196 / 216 / 225 ms（609 帧 + 1445 帧压测）
  - 吞吐：约 5 FPS，满足 ≤5 pcs/s 产线
  - 模型：FP16，filter 7.5MB + 主判类 7.5MB
  - 运行模式：step 按需推帧（09-21 落地，上位机发 next 才推一帧）
  - 自启：S99board → start_cascade.sh，掉电重启自动恢复级联
  - 长期机制：看门狗 1min / 健康 5min / 磁盘 6h / 误检监控 1h
- 说明：INT8 暂不可用（RKNN 分类头异常，已文档化）；板端归一化必须成对（std=255 ↔ uint8 NHWC）

## 6. 数据口径纪律（写页时必须遵守）

- **精度一律用 holdout 182 张口径**（隔离集）。全 val 360 的 0.783 只在讲"训练演进历史"时出现，并标注"全 val 口径"。
- **合成数据 0.959 不得作为 NEU 成绩**；如需出现，只能作为"合成数据虚高"的反例。
- **16 类体系 ≠ 16 类实测精度**：P1/P2/P10 出现的"16 类"一律指**类别体系与全链路就绪**，
  实测精度结论（0.7393 / 0% / 各类 R·P）**仍只对应已训练的 6 类**，两者不可混说。
